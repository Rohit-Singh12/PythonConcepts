# PythonConcepts
Learning some less common and advanced python concepts

## Concurrency and Parallelism

This repository contains a detailed guide on concurrency and parallelism in Python. See the full document in `Concurreny_and_Parallelism/README.md`.

Key topics covered:

- **GIL (Global Interpreter Lock)** — what it is and how it affects concurrency in CPython
- **Threads and Processes** — differences, trade-offs, and real-world analogies
- **concurrent.futures** — `ThreadPoolExecutor` and `ProcessPoolExecutor` usage patterns and pitfalls
- **multiprocessing** — spawn vs fork behavior and `if __name__ == "__main__"` requirements

For the full contents, examples, and explanations, open: `Concurreny_and_Parallelism/README.md`.
